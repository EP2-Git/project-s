# Project provenance

Project S was developed privately before its public source history began. The
owner-retained records date to 2025-04-04, and the owner reports that the first
product work began in Lovable. Those records and their private commit identifiers
remain archived separately.

The public source cut is prepared from an owner-controlled, privately validated
snapshot. Only files tracked by the approved snapshot cross the export boundary.
The public history is then constructed as a small set of coherent commits from
that sanitized tree. Once the final gates pass, exact public identity and
verification will be recorded in the immutable pre-release and its linked CI
runs, not by exposing private source identifiers.

The clean root is a security and privacy boundary, not an attempt to erase the
project's chronology. Private history contained environment and provider
configuration that is not appropriate for public redistribution. No private Git
objects, ignored environment files, credentials, production data, real booking
data, archives, or generated demo evidence may cross the boundary.

This chronology is not a claim of trademark priority, trademark clearance,
general availability, or production readiness. “Project S” is the working public
project identity for this open-source pre-alpha.
